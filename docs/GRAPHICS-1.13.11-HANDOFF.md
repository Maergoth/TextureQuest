# TextureQuest 1.13.11 local handoff

This candidate is local only. GitHub publication remains held; public main and
the latest public release stay unchanged. Texture data remains1.3.0 and the
seven non-renderer native payloads are retained. Generation remains paused.

Particle lighting now distinguishes an unavailable allocation service from a
valid zero budget. A brief service gap preserves already committed light and
shadow-map identities, using the current retained energy. Fade, expiry, reduced
limits, zero strength, Off and scene invalidation still retire lights. This
avoids unnecessarily rebuilding an entire selected set through the serial map
queue when service resumes.

Nearby particle contributions are grouped into4-unit world voxels before
publication, using their combined energy and weighted centre. This reduces
nearly coincident lights generated by fine-grid splats. The dedicated shadow
bank layout and HLSL remain unchanged from1.13.10. The existing2-second hold and
1-second fade still cover only previously observed sources.

replay their weighted T0 material normals. The shader disassembly proves these
base passes use the same normal-map weighting as the existing lamp replay;
rejecting all base passes left smooth models on flat geometric fallback.
Admission stays limited to those exact opaque shader pairs and retains the
existing texture, transform, resource-version and depth guards. Other base
profiles remain fallback. The TBN shader itself is unchanged.
