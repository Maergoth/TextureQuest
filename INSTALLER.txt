TextureQuest 1.5.1 — Windows x64

1. Patch EQ2 Origins, then close the game and launcher.
   If you replaced PAKs, restore stock files before choosing a hook.
2. Extract the whole app outside your game folder. Keep data beside the EXE.
3. Open TextureQuest, choose your game folder, then Download / Resume.
4. Choose an install mode, click Install, and wait for Ready.

Graphics hook (default): game files unchanged; Numpad * switches quality.
Memory hook: game files unchanged; no live quality switching.
Replace PAK files: changes archives; no background process. Reinstall after patches.
Hover each info icon for details.

INSTALL ONCE, THEN PLAY NORMALLY
Both hooks start at Windows sign-in, including after a reboot. Launch EQ2
through your usual EXE, shortcut or launcher. TextureQuest can stay closed.
Keep the app and data folder in place. Open the installer and click Uninstall
to disable the hook. An open game keeps it until that game closes.

SWITCH QUALITY
Press Numpad * while EQ2 is focused. Use Shortcut to change the key.
Dual-load on caches comparisons for faster switching; off loads them on demand.
The hotkey works either way.

PATCHES & UPDATES
If game archives changed, close EQ2, then Uninstall → Install to refresh the
hook cache. Automatic refresh is unfinished. Replace mode may need reinstalling.
Get app update downloads, verifies, installs and restarts the app, keeping data
and downloads. Close EQ2; uninstall the hook when prompted, then reinstall it.
To restore stock after Replace mode, use the official EQ2 patcher.

The unchanged pack includes 24,693 textures in 310 archives, including recovered
Maj'Dul textures. New generation is unfinished and is not included.
Graphics comparisons use a bounded cache; some textures may remain upscaled
in Original mode. Runtime injection is not officially approved; compatibility
and account-policy risk are unquantified. Tested on Windows EQ2 Origins.
This unofficial app is unsigned. Third-party notices are included.
