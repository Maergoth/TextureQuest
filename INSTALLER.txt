TextureQuest — Windows x64 installer

1. Extract this whole folder to a writable location outside your game folder.
   Keep TextureQuest.exe and _internal together. Python is not required.
2. Patch EverQuest II Origins, then close the game and launcher.
3. Open TextureQuest.exe and choose the folder containing EverQuest2.exe and paks.
4. Click Download / Resume. The installer checks GitHub's latest published
   release and downloads what it needs. You do not need a texture ZIP already.
   You can pause and resume; saved downloads are kept and reused automatically.
5. Click Install TextureQuest after verification. Downloading never installs
   anything automatically. Wait for installation verification to finish.

AFTER A GAME PATCH
Rerun this installer, click Download / Resume, then Install TextureQuest.
Saved downloads are rechecked and reused, so patching does not require the
whole pack to download again. Files that already match are skipped.

UPDATES
The app checks for the latest release on startup and before preparing a pack.
Maintenance & updates > Check for updates performs the same check in the app.
Compatible releases are downloaded by this installer; a changed release format
requires the newer installer linked on GitHub. Checking never installs files.
If the latest release cannot be verified, retry when the connection is working.
Your saved downloads stay intact.

Keep the data folder alongside TextureQuest.exe. When moving to a new installer
folder, move data with it to retain downloads, caches and installation records.
Do not discard data/games. Matching installed textures can also be reused.

WHAT IS DOWNLOADED
The current pack combines the original 27.8 GB base with complete updated
archives. You do not need to run an old installer first. The latest manifest
chooses the exact packages automatically; each archive retains unrelated files.
The installer checks GitHub's manifest asset SHA-256 and size, then verifies
every download, prepared VPK and installed VPK against that manifest.

DOWNLOADS AND SPACE
Allow room for downloaded ZIPs and one complete prepared archive set, plus
growth and one staged archive on the game drive. Saved downloads remain for
future reinstalls. Older prepared caches remain available during an update.
No extra set of split download chunks or original game backups is created.

Clear downloaded files & cache explicitly removes this app's saved downloads
and prepared copies. Game files and installation records stay. Reinstalling
after clearing them may require downloading the pack again.

SIDELOAD
The Sideload checkbox is disabled in this build. No tested EQ2 texture-injection
backend is included. Installation replaces game archives.
We don't know what's more legal, replacing the game files or hooking the process. If Daybreak hates you, they might ban you. Be warned.

RESTORE STOCK
Choose Maintenance & updates > Return to original textures, then run the
official EQ2 patcher. Modified bytes remain until the patcher replaces them.
The installer does not restore stock bytes or make game backups.
