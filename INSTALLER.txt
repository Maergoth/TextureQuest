TextureQuest 1.13.21 — Windows x64

Smoother particle shadows; quality presets preserve visual preferences.

PRESS HOME TO SHOW OR HIDE SETTINGS. Choose the TextureQuest tab.
Show FPS, Frame Gen and Quality Presets are at the top. Individual controls are
in Advanced; captures, statistics and performance recording are in Debug.

1. If you used Replace PAK mode, restore stock files with EQ2's patcher first.
2. Close EQ2. Extract outside the game folder; keep data beside the EXE.
3. Select your game folder, components and Quality Presets, then apply changes.
4. Launch EQ2 normally, including after reboot. TextureQuest can stay closed.

Textures are required. Graphical Effects / DLSS includes lighting, shadows,
ambient occlusion, filtering, optional frame generation and neural rendering on
supported hardware. Upscaling and Reflex driver mode have been removed.

Quality presets are available in this installer and in the in-game panel:
- Low: RTX 2060 starting point; 64 shadow slots, 32 emissive lights, 16 particle
  lights and 8 particle character shadows. Object emission and sun effects off.
- Medium: RTX 3070 starting point; 128 / 96 / 32 / 24. Adds object emission.
- High: RTX 4080 starting point; 256 / 256 / 64 / 64. Adds surface-light smoothing
  and sun processing.
- Max: RTX 5090 starting point; 512 / 512 / 128 / 128, full supported capacities.
All presets enable 16x anisotropic filtering, AO, point/character shadows and
particle emission. Presets preserve light strength/radius and shadow softness.
These are starting budgets, not measured FPS guarantees. A busy scene or higher
resolution can need a lower tier. Custom shows when manual settings differ.

Selecting a preset applies performance features and capacities. Brightness,
radius, shadow softness/strength, colour and other appearance settings survive.
Particle strength 1x equals the former 5x; saved values migrate without changing
their brightness. Frame Gen and Neural Rendering remain independent and start
off. Smooth text, rebuilt lamps and corrective sun direction start off on fresh
profiles; presets preserve their existing choices.

Frame Gen offers 2x / 3x / 4x where supported. Neural Rendering is under Advanced.
Motion is estimated; more processing costs GPU time. A game cap near 60 FPS can
help pacing. Home never pauses enabled processing. Keep native lighting,
material shaders and GPU shadows enabled. Native game INIs and bloom are unchanged.

Numpad * switches textures and graphics Original/TextureQuest without changing
individual choices. Use Shortcut to change that key. Other ReShade effects remain.

The recent qualified source and visibility improvements remain active. This
release lets particle shadows follow smaller movements of the already-smoothed
light source, with a bounded allowance for extra shadow-map updates. The failed
150 ms shadow fade stays removed. Crowded scenes and source reassignment can
still step; this is not a measured FPS improvement. Offscreen history cannot
discover game-culled sources; unsupported model shaders retain fallback.

Click What's new for the changelog bundled with the installer. Developers can
read the same history on GitHub:

Texture data remains 1.3.0: about 17.7 GB downloads and 27.8 GB local DDS. Keep
data. The unfinished generation batch is not included. No game PAK changes or
background watcher. Get app update verifies, replaces and restarts the app,
then refreshes the owned hook through normal setup. Unchanged texture preparation
is reused. After a game patch, Verify / Update textures rebuilds stock matching.

Close EQ2 before install, update or uninstall. Uninstall removes only unchanged
owned files. Later user settings and unknown files are preserved. Existing
compatible ReShade is reused; third-party notices and modified source are included.
