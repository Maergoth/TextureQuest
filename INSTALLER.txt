TextureQuest 1.9.0 — Windows x64

1. Patch EQ2 to stock first if you previously used Replace mode, then close EQ2.
2. Extract the app outside the game folder. Keep data beside TextureQuest.exe.
3. Choose your game folder, then Download / Resume.
4. Click Install graphics hook. Launch EQ2 normally, including after reboot.

Numpad * switches Original/Upscaled. Use Shortcut to change it.
TextureQuest can stay closed while playing. Keep the data folder in place.

Textures download as ZIP chunks containing individual DDS files. The app verifies
and extracts the DDS; it never downloads replacement PAKs or rewrites game archives.
Identical stock textures share one existing upscale. Known later corrections win.

The hook is a stock ReShade add-on. It adds TextureQuest.addon64 and
TextureQuest.ini; it installs official full-add-on ReShade as dxgi.dll only if no
ReShade is present. Existing full-add-on ReShade is reused. Standard ReShade needs
upgrading; unknown proxies are preserved and installation stops.

Close EQ2 to install, uninstall or activate updates. Uninstall removes only owned,
unchanged hook files; saved DDS files are kept. Remove an old graphics hook before
installing this version. Settings can remove an old Memory hook.

Unchanged stock textures keep matching after patches. Verify / Update textures
refreshes the local stock map. Changed source assets stay original until supported.
Get app update downloads, verifies and restarts the app, keeping data intact.

Graphics hooks are not officially approved; account-policy risk is unknown.
This community app includes third-party notices. The unfinished generation batch
is not part of the published DDS source.
