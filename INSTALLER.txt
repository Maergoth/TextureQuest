TextureQuest 1.7.0 — Windows x64

1. Patch EQ2 Origins, then close EQ2.
   Restore stock PAKs first if you previously used Replace mode.
2. Extract the whole app outside the game folder. Keep data beside the EXE.
3. Open TextureQuest, choose your game folder, then Download / Resume.
4. Choose an install mode and click Install. Wait until installation finishes.

GRAPHICS HOOK — DEFAULT
Adds d3d11.dll and TextureQuest.ini beside EverQuest2.exe. Existing EXE, PAKs
and ReShade settings stay unchanged. No background watcher or startup task.
Launch EQ2 normally, even after reboot; TextureQuest can stay closed.
Keep the app and data folder in place.

Numpad * switches Original/Upscaled while EQ2 is focused. Use Shortcut to change
it. Upscales load on demand. Ambiguous/unmatched textures remain original.
Close EQ2, then Uninstall graphics hook to remove our two files. Downloads stay.

REPLACE PAK FILES
Copies textures into game archives. No graphics hook; reinstall after patching.
Use the official patcher to restore stock PAKs. Close EQ2 before installing.
The two modes cannot be combined. Hover the info icons for details.

OLD HOOKS
Close EQ2 and Uninstall the old Graphics hook before installing this version.
For Memory hook, use Settings → Uninstall old Memory hook first.

PATCHES & APP UPDATES
Unchanged texture content still matches after patching. Changed assets stay
original until mappings are updated. If the patcher removes our DLL, reinstall.
Existing third-party graphics proxies are never overwritten.
Get app update downloads, verifies, replaces and restarts the app, preserving
data and downloads. Close EQ2; uninstall the hook when prompted, then reinstall.

Texture pack 1.2.3 is unchanged: 24,693 replacements in 310 archives, including
recovered Maj'Dul textures. Unfinished new generation is not included.
Graphics cache limits can leave textures original. Tested on Windows Origins;
all assets, other add-ons and future clients are not fully validated.
Neither mode is officially approved. Account-policy risk is unknown.
