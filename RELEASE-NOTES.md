# TextureQuest 1.1.1

The installer now checks the latest published texture release, downloads the files it needs, and keeps verified downloads for reuse. You do not need a separate `Texture-Pack.zip`.

Download **TextureQuest-Installer-1.1.1-windows-x64.zip**, extract it to a writable folder outside the game, and run **TextureQuest.exe**. Choose the game folder, download/prepare the pack, and click **Install TextureQuest** with the game and launcher closed.

**After a game patch, rerun the installer.** There is no file protection step. The installer reuses files that still match the current release and downloads new or missing files.

The texture content is unchanged from 1.1: the complete installation includes 310 archives and 23,282 replacement textures, including the selected 4K creatures and surfaces. Existing 1.0 and 1.1 texture downloads remain valid.

Sideload is still unavailable in this consumer release while the separate Qeynos Guard runtime trial is tested. Installation replaces game PAKs only when you click Install. The [README](https://github.com/Maergoth/TextureQuest#readme) includes examples and limitations.
