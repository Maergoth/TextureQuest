TextureQuest 1.3.7 contains app 1.3.5 with automatic app updates. Get app update downloads and verifies the new installer, stages its managed app files, closes the current app, applies the update, and restarts TextureQuest. The data folder, saved texture downloads and installation history are preserved. App updating does not install textures or launch the game.

Users on app 1.3.4 or earlier need one final manual upgrade: close the old app, extract this installer into a new writable folder outside the game, and move the existing data folder alongside the new TextureQuest.exe. Older apps open the GitHub release page; app 1.3.5 can apply future app updates directly. Keep the extracted files together.

Textures remain version 1.2.3: the same 24,693 textures across 310 complete archives, with every archive byte identity and download URL unchanged. The 312 recovered Maj'Dul/Desert of Flames textures, Ratonga repair, selected 4K textures, effects, alpha maps and other prior updates remain included. The new app bundles this current manifest. Additional missed-texture generation remains unfinished and is not part of this app-only release.

Texture downloads and installation remain separate actions. Use Download / Resume, then close EverQuest II and its launcher before clicking Install TextureQuest. Launch Game starts EverQuest2.exe directly after installation. App and texture versions are checked separately under Settings > Check for updates; if an app update cannot be verified or applied, the app reports the problem and keeps user data. Sideload remains unavailable.
