TextureQuest app 1.3.4 introduces a compact launcher layout with a main Launch Game button. Progress and Pause stay in the main window without scrolling, while longer status messages scroll independently.

After installation, the success dialog offers Launch Game and Close. Launch Game starts the selected EverQuest2.exe directly, just like the main window's button. It never opens the game patcher. Close dismisses the dialog without starting anything. The selected game folder is validated before launching, and an already running game or launcher must be closed first.

This release changes the app only. Texture version remains 1.2.2: the same 24,381 textures across 310 archives, with the existing Ratonga, 4K, effects and alpha updates preserved. Every VPK byte identity and download URL is unchanged, so saved matching texture downloads are reused.

Close the old app before upgrading, and keep its data folder alongside the new TextureQuest.exe. App and texture updates are checked separately under Settings > Check for updates. Downloads never install or launch the game automatically. Sideload remains unavailable.
