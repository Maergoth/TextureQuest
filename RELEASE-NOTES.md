# TextureQuest 1.0

A complete EverQuest II Origins texture pack focused on retaining the original style and art direction while adding detail to armor, creatures, signage, architecture and terrain.

**Start with `TextureQuest-Installer-1.0.0-windows-x64.zip`.** Extract it, run TextureQuest.exe, download the pack, select your game folder and click Install with EQ2 and its launcher closed.

The pack contains23,277 textures in310 complete archives, including the approved character/Ratonga repairs and +15% contrast/+15% saturation finish. Full download:27.8GB. Allow roughly56GB of free working space in addition to the game.

Patch first. Reinstall after game patches. Use EverQuest2.exe directly for ordinary play; the launcher can replace the textures. Uninstall unlocks files, and the official patcher restores stock.

The14 `.zip.001`–`.zip.014` assets are parts of one exact ZIP; the installer handles them automatically. GitHub's Source code downloads do not contain the pack.

Higher detail can expose original UV seams and tiling; AI-generated fine detail and some character/material variants remain imperfect. See the README for comparisons, limitations and problem-reporting instructions.
