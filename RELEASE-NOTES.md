TextureQuest 1.3.6 publishes texture version 1.2.3 with 312 recovered 2K textures: 137 from the Maj'Dul recovery and 175 other Desert of Flames textures. One complete updated exp01_ZDDS archive includes these textures while retaining its earlier released content.

The full pack now contains 24,693 textures across 310 archives. All 309 other archive files and their download URLs are unchanged. The previous Ratonga repair, selected 4K textures, effects, alpha maps and other released updates remain included. Additional missed-texture generation is continuing; this release does not claim that all remaining low-resolution textures are complete.

App 1.3.4 and its installer ZIP are unchanged. Existing app 1.3.4 users can choose Settings > Check for updates, then Download / Resume to prepare texture version 1.2.3. Matching downloads are reused; only the changed archive needs downloading when the previous cache is complete. The unchanged installer still bundles a 1.2.2 fallback, and its online startup check selects the current textures. Offline use does not acquire the new texture update.

Close EverQuest II and its launcher before clicking Install TextureQuest. Downloading never installs or launches the game automatically. After installation, Launch Game starts the selected EverQuest2.exe directly; Close dismisses the dialog without starting it. Keep the app's data folder for future updates and reinstalls. Sideload remains unavailable.
