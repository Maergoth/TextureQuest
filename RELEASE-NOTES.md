TextureQuest 1.4.2 fixes the app-update prerequisite for background-loader users. An available Get app update button remains clickable and asks whether to uninstall the owned loader and continue. Active EQ2 sessions or unknown ownership prevent updating. Reinstall the background loader after the app update; the data folder, verified downloads and installation history are preserved. In app 1.4.1 and earlier, uninstall the loader manually before Get app update if its button is disabled.

The installation-mode explanations and hover info icons introduced in 1.4.1 remain. Replace PAK files is recommended because it uses the game archives directly without runtime injection. Background texture loader keeps game PAKs, settings and shortcuts unchanged by using a private cache, per-user watcher and injected DLL. The loading-method recommendation is not a promise of account-policy compliance or official approval.

Background mode has a successful initial in-world test on one Windows Origins client; other client versions and every launch path are not fully validated. Keep the portable app and data folder in place. After a patch changes game archives or indexes, uninstall and reinstall the background loader to refresh its cache; automatic refresh is unfinished. Attached clients retain the loader until they close.

Textures remain 1.2.3: the same 24,693 textures across 310 archives, including the recovered Maj'Dul/Desert of Flames textures, with unchanged archive bytes and download URLs. This app-only release retains the same 1.3.7 manifest and portable loader payload. Additional generation is unfinished and is not included. No game installation, GPU setting or generation recipe changes are part of this release.
