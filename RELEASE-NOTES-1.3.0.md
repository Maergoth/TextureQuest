# TextureQuest 1.3

[Download the Windows app](https://github.com/Maergoth/TextureQuest/releases/download/v1.3.0/TextureQuest-Installer-1.3.0-windows-x64.zip)

TextureQuest now downloads ready-to-use VPK archives directly. It keeps one
texture cache in `data/downloads` for installation and future sideloading,
removing the need for a second extracted pack. The texture contents are the
same as 1.2.0: 310 complete archives and 23,282 replacement textures.

Close the old app, extract this app into a new folder, and move your existing
`data` folder beside `TextureQuest.exe`. Matching saved textures are reused;
the app moves verified legacy prepared archives into the single cache and
removes recognized redundant texture ZIPs and superseded saved VPKs after verification. Changed or
unrecognized files are kept.

Patch EQ2 first, then close the game and launcher. Open TextureQuest, download
or verify the textures, and click **Install TextureQuest**. Rerun it after game
patches. The app checks GitHub for texture and app updates automatically.

Full-pack sideload is still under development and remains disabled.

Older installers use the retired bulk texture ZIP downloads. Upgrade to this
app for new downloads and keep your existing `data` folder to reuse its files.

[Installation instructions and comparisons](https://github.com/Maergoth/TextureQuest#download-and-install)
